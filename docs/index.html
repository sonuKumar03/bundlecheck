Designed for Angular applications

Everything needed for bundle optimization and CI budget verification.

🔍 Dependency Tracer (why)

BFS static import graph traversal that pinpoints the exact chain of source files importing any library into initial JS.

💡 Optimization Advisor (suggest)

Detects heavy third-party utilities, eager component routes, and duplicate packages with estimated byte reductions.

🗜️ Real Gzip Wire Sizing (--gzip)

Calculates real physical file compression and projects actual over-the-network wire transfer sizes per NPM package.

📊 Baseline & Measure (measure)

One-command reference baseline in .bundlecheck/baseline.json. Track signed before/after deltas across refactors.

🤖 Universal AI Agent Skill

Pre-configured agent skill for Antigravity, Claude Code, Cursor, and Codex with step-by-step optimization workflows.

🛡️ CI Budgets & PR Comments

Official GitHub Action and markdown reporting engine that posts rich, sticky size diffs directly on pull requests.

Official GitHub Action

Guard against bundle regressions on every PR automatically.
