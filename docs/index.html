Everything you need for Angular bundle health

From interactive terminal refactoring to automated CI gating and AI agent loops.

🔍

Dependency Tracer (`why`)

BFS import graph traversal that shows the exact chain of source files importing any library into your bootstrap bundle.

💡

Automated Optimization Advisor

Detects heavy utilities in initial JS, eager components in routes, and duplicate libraries with estimated byte savings.

🗜️

Real Gzip Wire Sizing

Calculates real physical compression ratios and projects actual network wire transfer sizes for every NPM package.

📊

Baseline & Measure

One-command baseline tracking in `.bundlecheck/baseline.json`. Measure signed deltas across refactors effortlessly.

🤖

Universal AI Agent Skill

Native `$bundlecheck` skill for Antigravity, Claude Code, Cursor, and Codex with step-by-step optimization playbooks.

🛡️

CI Budgets & PR Comments

Official GitHub Action and markdown reporting engine that posts rich, sticky size diffs directly on pull requests.

Add to GitHub Actions in 4 Lines

Guard against bundle regressions on every Pull Request automatically with our official GitHub Action.

# .github/workflows/bundle-guard.yml
- name: Run BundleCheck & Post PR Report
uses: sonuKumar03/bundlecheck@v0.1.1
with:
post-comment: 'true'
max-initial: '350KB'
max-total: '1.2MB'
